# Theda's album storage!
This is a little program I wrote to store a collection of albums that I have said "I'll listen to it eventually" to, and this program brings the eventually to whenever the program rolls the random number that is equal to that album.
It allows for spotify integration, its very simple integration, but still integration none the less! All it does is allow you to add albums with added to the program with an associated spotify link to be added to the queue of a current player.
